# The Hooks Store — specification package

- `SPEC.md` — the product and build specification (what to build, data, chains, fees, design, acceptance criteria, job plan).
- `mockup/index.html` — the clickable design mockup. Open it in a browser. Sample data only; nothing sends transactions.
- `jobs/` — the five IMD job bodies that implement the spec, in order, with a README on how to check and pay for them.

Everything here is meant to be pushed to a public GitHub repository so the first IMD job can import it.
